# Pi 0.5 (Base)

Official Pi 0.5 LIBERO checkpoint from Physical Intelligence
(`gs://openpi-assets/checkpoints/pi05_libero/`).

For the expert-only fine-tuned variant, see
[pi05_expert_only.md](pi05_expert_only.md).

## Shared Setup

### 1. Clone

```bash
cd eval_scripts
git clone https://github.com/Physical-Intelligence/openpi.git pi05
cd pi05
git submodule update --init --recursive
```

### 2. Environment Setup

OpenPI uses a server/client split (the LIBERO sim runs in one process and
queries a policy server over HTTP). Both processes need their own env.

#### Policy server (JAX)

```bash
conda create -n libero-para-pi05-server python=3.11 -y
conda activate libero-para-pi05-server

# install openpi + JAX (GPU build)
pip install -e .
pip install jax[cuda12_pip] -f https://storage.googleapis.com/jax-releases/jax_cuda_releases.html
```

#### LIBERO client (PyTorch + LIBERO sim)

If you already have openpi's `openpi-libero` env (created by the openpi LIBERO
example), you can **skip this step** — it already has `openpi_client`, `libero`,
`robosuite`, and a compatible PyTorch. Just activate it and confirm:

```bash
conda activate openpi-libero
python -c "from libero.libero.envs import OffScreenRenderEnv; \
           from openpi_client import websocket_client_policy, image_tools; \
           print('client env OK')"
```

Otherwise, create a fresh env:

```bash
conda create -n libero-para-pi05-client python=3.8 -y
conda activate libero-para-pi05-client

cd third_party/libero && pip install -e . && cd ../..
pip install -e packages/openpi-client
pip install -r examples/libero/requirements.txt \
    --extra-index-url https://download.pytorch.org/whl/cu113 \
    --index-strategy=unsafe-best-match
pip install "numpy<2" robosuite==1.4.0 bddl==1.0.1 future easydict matplotlib gym==0.25.2
export PYTHONPATH=$PYTHONPATH:$PWD/third_party/libero
```

(Both env names are used interchangeably below — replace `libero-para-pi05-client`
with `openpi-libero` if you took the shortcut.)

### 3. Install LIBERO-Para

```bash
cd ../../   # back to LIBERO-Para root
pip install --config-settings editable_mode=compat -e .
python -c "from libero.libero import set_libero_default_path; set_libero_default_path()"
```

## Run (Base variant)

Two terminals — server then client.

### Terminal 1: policy server (loads `pi05_libero` checkpoint)

```bash
conda activate libero-para-pi05-server
cd eval_scripts/pi05
uv run scripts/serve_policy.py --env LIBERO --port 8000
# the checkpoint at gs://openpi-assets/checkpoints/pi05_libero/ is downloaded
# automatically on first launch.
```

### Terminal 2: LIBERO-Para client

Run from the **LIBERO-Para repo root** (not from inside the openpi clone):

```bash
conda activate libero-para-pi05-client    # or: conda activate openpi-libero
cd /path/to/LIBERO-Para
export MUJOCO_GL=egl   # use glx if egl fails
python eval_scripts/examples/eval_pi05.py \
    --host localhost --port 8000 \
    --model_name pi05 \
    --gpu 0 --seed 7 \
    --output_dir ./logs_para/pi05/seed7/
```

## Docker shortcut (recommended)

Skips both env setups; uses the official compose file.

```bash
cd eval_scripts/pi05
sudo xhost +local:docker
SERVER_ARGS="--env LIBERO" docker compose -f examples/libero/compose.yml up --build
# if EGL errors:
MUJOCO_GL=glx SERVER_ARGS="--env LIBERO" docker compose -f examples/libero/compose.yml up --build
```

## Evaluating on Original LIBERO Suites

Same script — point `--bddl_dir` / `--init_dir` at the standard suite.
Mode is auto-detected from filenames.

```bash
python eval_scripts/examples/eval_pi05.py \
    --host localhost --port 8000 \
    --gpu 0 --seed 7 \
    --bddl_dir libero/libero/bddl_files/libero_goal \
    --init_dir libero/libero/init_files/libero_goal \
    --output_dir ./logs_para/pi05-goal/seed7/
```

## Notes

- Architecture: PaliGemma 2 VLM + flow-matching action expert
- Checkpoint source: `gs://openpi-assets/checkpoints/pi05_libero/` (auto-downloaded)
- Config name: `pi05_libero`
- Action horizon: 10
- Action space: 7-DoF
- Original LIBERO-Goal SR (paper): ~98.0
- Paper / blog: https://www.physicalintelligence.company/blog/pi05
